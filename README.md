# 🔐 SecureHub

<img width="937" height="429" alt="image" src="https://github.com/user-attachments/assets/532976b2-0c95-49ec-82dd-6f9afcbcd050" />


SecureHub is a full-stack **MERN authentication and authorization project** built to practically understand how authentication, authorization, JWT security, protected routes, role-based access control, and admin user management work in a real-world web application.

The project provides different permissions for **Admin** and **Regular User** accounts.

---

## 🚀 Project Overview

SecureHub demonstrates a complete authentication and authorization workflow using:

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- React Router
- REST APIs
- Role-Based Access Control

The main purpose of this project is not just to create a login and registration system, but to understand how a production-style authentication system works between a frontend and backend.

---

# ✨ Features

## 🔑 Authentication

- User registration
- User login
- Password hashing using bcrypt
- JWT authentication
- Token-based authentication
- Login validation
- Logout functionality
- Protected dashboard
- Authentication middleware
- Account status checking
- Active/inactive user handling
- Authentication error handling

---

## 🛡️ Authorization

SecureHub implements **Role-Based Access Control (RBAC)**.

There are currently two roles:

```text
admin
user
```
